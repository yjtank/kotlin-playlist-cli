# Kotlin Playlist CLI

Projeto de estudo em Kotlin: uma aplicação de linha de comando para gerenciar uma playlist de músicas.

## Funcionalidades

- Listar as músicas da playlist
- Adicionar uma música
- Remover uma música pela posição
- Buscar músicas pelo nome
- Escolher uma música aleatória
- Encerrar o programa pelo menu

## Como executar

1. Abra o projeto em uma IDE com suporte a Kotlin, como o IntelliJ IDEA.
2. Execute o arquivo `src/Main.kt`.
3. Use as opções exibidas no menu para interagir com a playlist.

## Tecnologias

- Kotlin
- Aplicação CLI (linha de comando)

## Objetivo

Este repositório faz parte dos meus estudos de Kotlin e serve para praticar listas mutáveis, funções, estruturas condicionais, laços de repetição e entrada de dados pelo terminal.
